# v09 실행 계약의 위치

현재 compiler가 사용하는 dtype·메모리·주소·DMA·누산 계약은
[docs/reference/execution_contract.md](docs/reference/execution_contract.md)에 정리했다.

명령 해독 예제는 [ISA와 실행 bundle](docs/current/09_isa.md),
vector 길이 등 미확정 사항은 [지원 범위와 남은 검토](docs/current/12_operations_limits.md)를 본다.
이 파일은 기존 코드 주석에서의 경로 참조를 유지하기 위한 안내다.
